一条命令装好

装完 cclaude 即为全局命令，任意目录直接用。

macOS / Linux

curl -fsSL {{.Site}}/install.sh | sh

Windows

# PowerShell
irm {{.Site}}/install.ps1 | iex

# 或 cmd.exe
powershell -c "irm {{.Site}}/install.ps1 | iex"

Windows 走 PowerShell 而不是 curl | sh：系统里没有 sh； 而且 irm | iex 是求值字符串、不受 ExecutionPolicy 限制，先下载成 .ps1 再执行反而会被默认策略拦下。

脚本会按你的系统与架构取对应产物，校验 SHA256 后才装进 PATH； 校验和直接写在脚本里，你可以先在浏览器打开 install.sh / install.ps1 读一遍再执行。

校验完整性

下载 SHA256SUMS 到产物同一目录，然后：

shasum -a 256 -c SHA256SUMS --ignore-missing   # Linux 用 sha256sum -c --ignore-missing

手动下载后 macOS/Linux 需 chmod +x 并自行放进 PATH；使用步骤见快速开始。
