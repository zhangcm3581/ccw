整台节点只做一次

纳管只把栈起起来，Claude Code 还没有上游账号的凭据，需要你上机登录一次。 本节点全部项目共用一个 claude-shared 卷，在任意一个项目容器里登录，其余项目自动共用 同一份凭据与同一个额度池。这一步后台还代劳不了。

{{if .AuthProjects}} {{$p := index .AuthProjects 0}}

先检查是否已登录

docker exec {{$p.Container}} claude auth status

输出 loggedIn: true 就已经好了，下面的不用做。

没登录就执行这段（tmux socket 名已按本节点的 project id 填好）

ssh {{.SSHTarget}}

docker exec {{$p.Container}} tmux -L {{$p.RemoteID}} new-session -d -s main -c /workspace claude
docker exec -it {{$p.Container}} tmux -L {{$p.RemoteID}} attach-session -t main

在附着的终端里跟着提示走完登录，然后按 Ctrl-b 松开再按 d 脱离。 不要按 Ctrl-c——那会把会话里的 claude 杀掉。
