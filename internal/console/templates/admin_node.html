重置节点

擦远端、留账，不可撤销
把这台机器擦回「装了 Docker 的干净机器」，用于反复重来的测试。
会销毁：ccw 的全部容器与命名卷、源码树 /srv/ccw—— 也就是 workspace 里的文件、Claude 授权凭据、节点自己的 Postgres（项目与 CDK）全部消失。
刻意保留：Docker 本身（重装要几分钟，precheck 会跳过，每轮能快很多）、 authorized_keys 里的托管密钥（删了 Console 就再也连不上）、 Console 库里的节点与域名分配（所以不用重填 IP、不用再等一次 DNS 生效）。
擦完点右上角「继续 / 重新部署」即为一次全新部署。要连 Console 的账一起清，用下面的「解除纳管」。

解除纳管

清账、不碰机器，不可撤销
只清 Console 这边的账，不碰那台机器。容器、数据卷、已授权的 Claude 凭据 都还在服务器上跑着，要真正下线得自己登机处理。删除后本节点的项目与 CDK 记录一并消失， /connect 也就查不到它们了；已分配的子域名会标记退役， 序号不回收，下一台机器不会拿到同一个。
