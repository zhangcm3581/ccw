快速开始

前提：已从下载页获取客户端，并拿到管理员签发的 CDK。

  1. 安装客户端 
    # macOS / Linux
curl -fsSL {{.Site}}/install.sh | sh

# Windows（PowerShell）
irm {{.Site}}/install.ps1 | iex

    装完 cclaude 即为全局命令。手动下载的方式见下载页。

  2. 确认接入地址

    管理员通常会连同 CDK 一起给出 API 域名；忘了或没拿到时，在查询页粘贴 CDK 即可查到（只上传公开前半段，密钥不离开你的设备）。

  3. 首次运行 
    cd ~/my-project                      # 同步以当前目录为根，先进入正确的项目目录
cclaude --api https://api-01.example.com    # 换成你的API域名；地址会记住，下次直接 cclaude
# 按提示输入CDK（不回显）

    登录后前台是云端 Claude 终端，后台每2秒同步当前目录。API地址与CDK保存在 ~/.ccw/config.json（仅当前用户可读）。

日常使用

断线重连

网络断开、休眠、关终端都不影响云端会话；重新运行 cclaude 即回到 tmux 现场。

同步范围

以运行目录为根双向同步。凭据类文件（.env*、.ssh/ 等）、.git/、node_modules/ 与符号链接不参与同步。

冲突处理

两端同时改同一文件时，不覆盖你的本地版本，云端版本另存为 *.conflict-remote-* 副本。

额度受限时

项目内部额度用尽会临时降级：终端暂停、同步只允许下载/删除/缩小；窗口恢复后自动回到正常模式，客户端不需要退出。

常见问题

提示 invalid_cdk？ CDK可能已被轮换或撤销。客户端会自动清除本地缓存的CDK（保留API地址），向管理员索取新CDK后重新运行输入即可，云端会话现场不受影响。
换机器/换项目？ cclaude --api ... 可随时切换接入地址；cclaude logout 清除本机保存的地址与CDK。
