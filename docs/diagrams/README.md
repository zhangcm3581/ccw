# 系统图谱

七张图覆盖 ccw 的结构、数据流与运维链路。**产物与源码一起提交**，看图不需要任何工具。

| 图 | 文件 | 内容 |
|---|---|---|
| 1 | `01-overview` | 系统全景：Console、节点与本地客户端 |
| 2 | `02-auth` | 登录与连接：从 CDK 到两把短期令牌 |
| 3 | `03-terminal` | 终端附着：tmux 会话为什么不会丢 |
| 4 | `04-sync` | 文件同步：三方判断与冲突保护 |
| 5 | `05-quota` | 用量采集与额度闸门 |
| 6 | `06-volumes` | 卷布局：授权一次，计量分家 |
| 7 | `07-bootstrap` | 节点纳管：bootstrap 12 步流水线 |

## 怎么看

- **一次看全部**：浏览器打开 `index.html`（纯本地，无外部依赖，深浅色自适应）
- **单张**：直接打开 `NN-*.svg`（矢量，缩放不糊）或 `NN-*.png`（2 倍图，方便贴进文档与聊天）

## 怎么改

源码是 `src/*.mmd`（Mermaid）。改完重新渲染：

```bash
./render.sh
```

依赖 Node，首次运行会用 npx 拉 `@mermaid-js/mermaid-cli`（需要联网）。配色在 `mermaid-config.json`。

## 图里的验证强度标记

图注上的标记与 `docs/STATUS.md` 同步：**真机验证**＝在真实部署上跑过；**仅单测**＝代码闭环但没上真机；**未实施**＝设计里有、代码里没有。改代码后请一并更新，别让图比代码更乐观。
